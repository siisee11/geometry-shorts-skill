# show.json 형식

`scripts/run.py <에피소드 폴더>`(= `make.py`)가 읽는 에피소드 파일. 경로(`borders`, 그림 파일)는 모두 show.json이 있는 폴더 기준이다. 결과는 같은 폴더의 `out/`에 생긴다(`video.mp4`, `sheet.png`, `stills/`).

## 목차

1. 최상위 키
2. 항목(entries)
3. 영토(geom)
4. 문양(flag)
5. 카메라와 타이밍
6. 계산되는 것
7. 스크립트

## 1. 최상위 키

| 키 | 기본값 (ranking / timeline) | 뜻 |
|---|---|---|
| `format` | `"ranking"` | `"ranking"` 또는 `"timeline"` |
| `title` | 필수 / 없음 | 제목 카드 줄 목록. `{...}` 안은 금색: `["동남아시아에서", "가장 큰 나라 {TOP5}"]`. 연대기에 넣으면 연대기도 제목 카드로 시작한다 |
| `entries` | 필수 | 항목 목록 (2장) |
| `order` | `"countdown"` / `"as_listed"` | countdown은 값이 작은 것부터(순위는 큰 값이 1위). as_listed는 파일 순서 |
| `unit` | `"km²"` / `""` | 등수 숫자 뒤에 붙는 글자(`"명"`, `"억 달러"` 등) |
| `step` | `10` / `1` | 카운터가 움직이는 단위 |
| `t0` | `3.1` / `0` | 첫 항목이 나오는 시각(초). 그 앞은 제목 카드. 연대기도 `title`이 있으면 3.1 |
| `period` | `3.308` / `1.98` | 항목 하나의 길이(초). 음악 템포도 여기서 정해진다(박자 4·8·16개 중 130BPM에 가까운 것) |
| `fps` | `60` | 영상 프레임 수. 명령의 `--fps`가 우선 |
| `tail` | `period` | 마지막 항목 뒤 길이 |
| `title_view` | 모든 항목을 담는 범위 | 제목 카드 카메라 범위 `[경도0, 위도0, 경도1, 위도1]` |
| `title_hold` | | 제목 카드 카메라를 뷰 두 개(시작, 첫 항목 직전)로 직접 지정 |

길이 = `t0 + period × (항목 수 − 1) + tail`. 쇼츠는 60초 이하, 이 장르는 15~35초가 보통이다.

## 2. 항목 (entries)

```json
{"name": "인도네시아", "geom": {"iso": ["IDN"]}, "value": 1904569, "flag": {"cdn": "id"}}
{"name": "남북국", "year": 800, "territories": [{"geom": ..., "flag": ...}, {"geom": ..., "flag": ...}]}
```

| 키 | 뜻 |
|---|---|
| `name` | 화면 이름. 한글 약 9자까지 |
| `value` | 등수의 숫자. `"auto"`면 영토 다각형의 측지 면적(km², `round` 단위로 반올림, 기본 10) |
| `year` | 연대기의 연도. 음수는 기원전(`-300` → "300 BC"). 연도 카운터는 이전 항목의 연도에서 이 연도로 0.45초 동안 바뀐다 |
| `rank` | 순위를 직접 지정(보통은 값으로 자동, 같은 값은 "공동 N.") |
| `geom`, `flag`, `flag_box` | 영토 하나일 때 |
| `territories` | 한 박자에 영토 여럿: `[{"geom", "flag", "flag_box"}, ...]`. 모두 한 판으로 같이 와이프된다 |
| `frame` | 카메라에 담을 범위 `[경도0, 위도0, 경도1, 위도1]`. 기본은 영토(가장 큰 조각의 5% 넘는 조각들)의 범위 |
| `hold` | 카메라를 뷰 두 개(`[[cx, cy, w], [cx, cy, w]]`, 메르카토르 도 단위: 중심 경도, 중심 y, 화면 폭)로 직접 지정. 보통은 `frame`으로 충분하다 |

## 3. 영토 (geom)

| 형태 | 뜻 |
|---|---|
| `{"iso": ["KOR", "PRK"]}` | Natural Earth 1:10m 국가(ADM0_A3). 여럿이면 합친다. 코드는 `scripts/countries.py <이름>` |
| `{"claim": [[경도, 위도], ...]}` | 다각형(또는 고리 목록)을 육지와 교집합. 역사 국가용 |
| `{"borders": "borders.json", "key": "goryeo"}` | 클레임 고리를 파일에서(`{"goryeo": {"claim": [[[x, y], ...]]}}`) |
| `+ "clip": [경도0, 위도0, 경도1, 위도1]` | 상자로 자르기(해외 영토 빼기) |
| `+ "minus": <geom>` | 다른 영토 빼기(백제 = 클레임 − 고구려) |
| `[<geom>, <geom>]` | 합 |

클레임 그리는 요령:
- 내륙 경계만 정확히 찍고, 바다 쪽은 해안선 바깥으로 넉넉히 둘러싼다.
- 경계가 강·산맥을 따르면 그 선을 몇 점으로 따라간다(점 10~40개면 쇼츠 화면에 충분).
- 이웃 나라끼리는 같은 경계선 점을 공유하거나, 한쪽을 `minus`로 빼서 틈과 겹침을 없앤다.
- 섬(제주 등)을 넣을지 뺄지 위도·경도로 정해 두른다.
- `--plan`의 값(`"value": "auto"`로 잠시 바꿔 보면)으로 면적이 알려진 수치와 크게 어긋나지 않는지 검산한다.

## 4. 문양 (flag)

| 형태 | 뜻 |
|---|---|
| `{"cdn": "fr"}` | flagcdn.com의 국기(ISO 3166-1 alpha-2 소문자) |
| `{"hanja": "高句麗", "field": [r,g,b], "ink": [r,g,b]}` | 바탕색 위 큰 한자(Noto Serif KR Black, 잉크 번짐). 옵션 `size`(상자 대비 최대 크기, 0.62), `disc`(글자 뒤 원 색), `vertical`, `centre`, `rough` |
| `{"draw": "<함수>", "args": {...}}` | `scripts/flags.py`의 코드 도형: `taegukgi`, `dprk`, `crescent`, `rings`, `big_taeguk` |
| `{"stamp": "emblem.png", "field": [r,g,b], "size": 0.6, "centre": [x, y]}` | 빨강 바탕에 검은 그림인 생성 이미지에서 검은 획만 따서 바탕색 위에 찍기 |
| `{"emblem": "dragon.png", "field": [r,g,b], ...}` | 단색 바탕에 그린 생성 이미지를 바탕색에 맞춰 얹기 |
| `{"image": "my.png"}` | 아무 이미지 |
| `{"color": [r,g,b]}` | 단색 |

이미지 국기(`cdn`, `image`)의 맞춤:
- `"fit": "auto"`(기본): 국기를 영토 상자에 1.6배까지 늘려 붙이고(이 장르의 문법), 그보다 길쭉하면 비율을 지키며 잘라 낸다. 잘라 낼 때 국기 중심은 영토의 시각적 중심(polylabel)에 맞춘다.
- `"fit": "stretch"`: 상자에 그대로 늘리기. `"fit": "cover"`: 늘리지 않고 잘라 내기.
- `"scale": 0.45`: 국기를 줄이고 나머지를 바탕색으로 채우기. 좁은 나라에 한 색 바탕 + 가운데 문양 국기용.

`flag_box`: 국기를 펼 상자. `"frame"`(기본, 영토 범위), `"main"`(가장 큰 조각: 제주처럼 멀리 떨어진 섬 때문에 국기가 늘어나지 않게), 또는 `[경도0, 위도0, 경도1, 위도1]`.

생성 엠블럼: `scripts/emblem_gen.py`는 로컬 ComfyUI의 Qwen-Image로 "채움 색 바탕 위" 그림을 뽑는다(아무 이미지 모델이나 같은 방식). 생성한 그림은 영토 위에 실제 크기로 얹어 보고 고른다(정면으로 날개 편 새는 크게 놓으면 문장 독수리처럼 보였다).

## 5. 카메라와 타이밍 (자동)

- 카메라: 항목마다 영토를 글자가 없는 화면 부분에 맞춰 잡는다(등수: 위쪽 7~70%, 연대기: 28~78%). 머무는 동안 초당 1.3% 줌인, 다음 항목으로 0.55초 동안 이동(이동 40% 지점에서 최고 속도, 짧은 이동은 중간에 5% 줌아웃).
- 전환: 박자 0.12초 뒤부터 0.45초 동안 지도 위를 북→남으로 쓸어내리는 와이프. 위쪽은 새 영토, 아래쪽은 이전 영토. 카메라가 빠를 때 모션 블러.
- 글자: 이전 라벨이 +0.155초에 반쯤 사라지고 새 라벨이 +0.235초에 반쯤 나타난다. 숫자는 +0.21초부터 0.45초 ease-out.
- 판: 그림자, 8px 옆면, 위성 지도의 지형 요철이 비치는 윗면.

## 6. 계산되는 것

`--plan`이 보여 준다: 순위(동점 처리), 순서, 각 항목의 카메라 뷰, 지도 범위와 해상도(가장 가까운 뷰가 선명하고 캐시 한 변이 12,000px 이하가 되게), 필요한 NASA 지도 조각. 계산 결과는 `out/plan.pkl`에 캐시된다(show.json이나 borders 파일이 바뀌면 다시 계산).

## 7. 스크립트

| 파일 | 하는 일 |
|---|---|
| `run.py` | 입구: 처음 한 번 패키지 환경을 만들고 아래 스크립트를 실행(`run.py <폴더>` = make.py, `run.py countries …`) |
| `make.py` | show.json → 계획·스틸·영상(`--fps`, `--status`) |
| `countries.py` | 나라 이름 → Natural Earth 코드, 국기 코드, 면적, 범위 |
| `mapkit.py` | 데이터 받기, 메르카토르 지도 캐시, 뷰, 마스크, 텍스처, 입체 판, 색 보정 |
| `ranking.py` | 렌더러(형식별 글자 배치 `LAYOUTS`, 와이프, 카운터, 모션 블러, 병렬 인코딩) |
| `flags.py` | 코드 국기·도형, 한자 글자, 생성 엠블럼 붙이기 |
| `music.py` | 합성 음악 |
| `emblem_gen.py` | 로컬 ComfyUI로 엠블럼 생성 |
